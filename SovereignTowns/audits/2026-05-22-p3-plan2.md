> **权威规格**:`audits/2026-05-22-p3-lookahead-design.md` §6(时间展开 solver)、§7(预测器)。

**Goal:** 把 `UnifiedGarrisonSolver` 从单 tick 图重写成 §6 的 T 层时间展开软预算图
(option A + K 平衡),并加威胁预测器,让合并 solver 获得「提前招兵 / 防遣散颤动 / 跨 tick
路途风险」前瞻能力。

**Architecture:** 单商品时间展开 min-cost-flow:节点 `G[S,R,τ]`(兵在城/兵种/tick)、
`Transit`、`RecOrigin`、`disbandGate`;跨时间边 = holding / 在飞 / 调拨;每边 K 分量 =
代理的 tick 数 × K(每条 source→sink 路径恒 T·K → 偏移抵消);decode 只取 layer 0
(receding-horizon MPC)。威胁经 `IHorizonForecast` 注入每 tick 的 tier value。

**Tech Stack:** C# net472,Bannerlord v1.3.15 Campaign API,项目内 `MinCostFlow` 引擎。

**项目约定(重要):**

    }
    public float Strength { get; }

类内方法:

```csharp
    /// <summary>
    /// 朝 <paramref name="target"/> 逼近的敌对军事队伍(以 target 为 TargetSettlement)
    /// + 各自估计 ETA(tick 数)。ETA = 直线距离 / 队伍速度 / tickHours。
    /// 无副作用。供 ThreatForecast(Part C)用。
    /// </summary>
    public static System.Collections.Generic.List<ConvergingHostile> EnumerateConvergingHostiles(
        Settlement target, float radius, int tickHours)
    {
        var result = new System.Collections.Generic.List<ConvergingHostile>();
        if (target == null) return result;
        var friendly = target.MapFaction;
        if (friendly == null) return result;
        tickHours = Math.Max(1, tickHours);
        try
        {
            var pos = target.GetPosition2D;
            var search = MobileParty.StartFindingLocatablesAroundPosition(pos, Math.Max(1f, radius));
            for (var p = MobileParty.FindNextLocatable(ref search);
                 p != null;
                 p = MobileParty.FindNextLocatable(ref search))
            {
                if (!IsHostileMilitary(p, friendly)) continue;
                if (p.TargetSettlement != target) continue;   // 只取明确以 target 为目标的
                float dist = (p.Position2D - pos).Length;
                float speed = Math.Max(0.1f, p.Speed);
                int eta = (int)Math.Round(dist / speed / tickHours);
                result.Add(new ConvergingHostile(HealthyStrength(p), Math.Max(0, eta)));
            }
        }
        catch (Exception ex)
        {
            Logger.Error($"HostilePartyScanner.EnumerateConvergingHostiles failed for '{target?.StringId}'", ex);
        }
        return result;
    }
```

> `IsHostileMilitary` / `HealthyStrength` 是 Plan 1 已有的私有方法,直接复用。
> `MobileParty.Position2D` / `.Speed` / `.TargetSettlement` 均 vanilla 既有(现有用例:
> `BaseSettlementVisitScheduler` 用 `.Speed`、`SupplyDemandGraph` 用 `.TargetSettlement`)。

```csharp
/// <summary>
/// 威胁预测(§7.2):tick 0 = 当前威胁;tick>0 = 把「ETA ≤ tick 的逼近敌军」按健康兵力
/// 总和映射成威胁等级,与当前威胁取较高者。宣战时机不可测 → 只吃已存在的逼近敌军。
/// </summary>
public sealed class ThreatForecast : IHorizonForecast
{
    private readonly float _radius;
    private readonly int _tickHours;

    public ThreatForecast(float radius, int tickHours)
    {
        _radius = radius;
        _tickHours = tickHours;
    }

    public RiskLevel ThreatAt(Settlement s, int tick)
    {
        var baseline = RiskAssessmentService.Assess(s).Level;
        if (s == null || tick <= 0) return baseline;
        try
        {
            float arrived = 0f;
            foreach (var h in HostilePartyScanner.EnumerateConvergingHostiles(s, _radius, _tickHours))
                if (h.EtaTicks <= tick) arrived += h.Strength;
            if (arrived <= 0f) return baseline;
            // 健康兵力总和 → 威胁等级。阈值为初值,须 in-game 调。
            RiskLevel bumped =
                arrived >= 150f ? RiskLevel.Critical :
                arrived >= 80f  ? RiskLevel.High :
                arrived >= 30f  ? RiskLevel.Medium :
                                  RiskLevel.Low;
            return (RiskLevel)Math.Max((int)baseline, (int)bumped);
        }
        catch (Exception ex)
        {
            Logger.Error($"ThreatForecast.ThreatAt failed for '{s?.StringId}'", ex);
            return baseline;
        }
    }
}
```
